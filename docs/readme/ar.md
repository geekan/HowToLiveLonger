تعرّف على الأبحاث المتعلقة بالغذاء والحركة والنوم والعادات اليومية، واختر تغييرات تناسب حياتك.

- **ثماني لغات:** الصينية والإنجليزية والإسبانية والفرنسية والألمانية والبرتغالية واليابانية والعربية.
- **تصفّح بسهولة:** ابحث عن موضوع، وصفِّ النتائج بحسب الفئة أو مستوى الأدلة، ورتّبها بالنقر على عنوان العمود. تظهر النتائج على الهاتف في بطاقات للقراءة.
- **أبحاث يمكنك الرجوع إلى مصادرها:** 61 سجلاً تضم نتائج بلغة واضحة وأفكاراً للحياة اليومية وروابط للمصادر الأصلية. مرّر المؤشر على مصطلح مثل HR أو انقر عليه لقراءة الشرح.
- **احتفظ بنسخة:** نزّل ملف CSV أو بيانات JSON الكاملة أو بطاقة للمشاركة. ويمكنك تنزيل المستودع وفتح `index.html` لتصفّح المحتوى دون اتصال.

## التطوير محلياً

يكفي Python 3.10 أو إصدار أحدث. لا حاجة إلى حزم إضافية أو خادم للتطبيق.

```sh
git clone https://github.com/geekan/HowToLiveLonger.git
cd HowToLiveLonger
python3 scripts/build.py
python3 scripts/validate.py --check-build
python3 -m http.server 8000
```

افتح <http://localhost:8000>. بعد تعديل القالب أو البيانات، أعد بناء الموقع والتحقق منه، ثم احفظ التغييرات في Git مع ملف `index.html` الناتج.

## بنية المشروع

| المجلد | المحتوى |
| --- | --- |
| [`src/`](../../src/) | قالب الصفحة: `index.template.html` |
| [`data/`](../../data/) | سجلات الدراسات والمصادر وقاموس المصطلحات |
| [`locales/`](../../locales/) | ترجمات الواجهة والدراسات، مع بطاقات القراءة في `readers/` |
| [`scripts/`](../../scripts/) | ينشئ `build.py` الموقع، ويفحص `validate.py` البيانات وإمكانية إعادة إنتاج الملفات الناتجة |
| [`assets/`](../../assets/) | الشعار والرسوم وملفاتها الأصلية |
| [`docs/`](../../docs/) | المقالات الأصلية وسجلات المراجعات السابقة وملفات README المترجمة |
| [`index.html`](../../index.html) | الموقع الناتج في ملف واحد للنشر على GitHub Pages والقراءة دون اتصال |

## الاستضافة والتحديثات

ينشر GitHub Pages المجلد الجذري لفرع `main`. يتيح ملف `.nojekyll` تقديم الملفات الثابتة الجاهزة مباشرة. ابنِ الموقع وتحقق منه محلياً، ثم ارفع التغييرات. لا حاجة إلى ملفات workflow مخصصة.
